SASES 隐私政策

SASES 非常重视您的隐私，我们的核心设计理念是“本地优先，数据主权归于用户”。本政策说明我们如何处理您的数据。

1. 本地优先与数据收集

默认离线：本系统默认情况下完全在您的本地设备上运行。您的聊天记录、知识库、个人隐私数据默认仅存储在本地设备（如 users.db），不会自动上传至任何官方服务器。

API Key 安全：您配置的大模型 API Key 通过本地环境变量加密存储，绝不会以明文形式离开您的设备。

2. 第三方调用说明

当您与 AI 对话时，您的输入数据将直接发送至您配置的第三方大模型厂商（如 DeepSeek）。本系统不中转、不截留这些数据，请查阅对应厂商的隐私条款以了解其数据使用规范。

3. 分布式网络（蜂巢）与中继

若您主动开启跨设备/跨节点通讯，节点间通讯采用 WireGuard 加密与内网穿透，保证传输链路的安全。中继节点（如 Node-A）仅处理加密的转发请求，不存储您的私密聊天内容。

4. 用户权利

由于数据完全归您所有，您可以随时通过本地文件管理直接导出或删除您的数据。若您在官方节点注册了账号，您也有权要求注销账号及清理云端中继缓存。

5. 免责条款

请注意防范本地网络环境安全。因用户自身设备中病毒、木马导致的数据泄露，本系统无法承担责任。
