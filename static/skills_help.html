SASES 技能（DSH 兼容）

技能放在项目目录：

data/skills/<技能名>/SKILL.md

也兼容单文件：

data/skills/<技能名>.md

格式

---
name: my-skill
description: 一句话说明这个技能什么时候用
---

# 技能标题

这里写具体步骤、约束、检查方式。

规则

  • 第一段必须是 YAML frontmatter，包含 name 和 description。
  • 选中技能后，正文会注入 system prompt。
  • 技能是“说明书”，不是工具；不会直接执行代码。
  • 建议一个技能只做一件事，正文不超过 6000 字符。

示例

---
name: verify-frontend
description: 修改前端后必须做语法和截图验证
---

1. 修改 static/ 后运行 verify_syntax。
2. 用 verify_ui 截图。
3. 失败先修复，不要结束。

同步

把目录或 .md 文件放进 data/skills，刷新页面即可在「能力 → 技能」里搜索并勾选。
