# SASES 自迭代有效性验证报告

## 实验背景

SASES（Seed-Apollo Self-Evolving System）的核心假设：**通过自动生成-验证-入库-微调的闭环，模型能力能持续提升。**

本实验用 4 个历史 LoRA 适配器（基于 `TinyLlama-1.1B-Chat-v1.0`）验证这一假设。

## 实验方法

- 基座模型：`TinyLlama/TinyLlama-1.1B-Chat-v1.0`
- LoRA 配置：r=8, alpha=32, target_modules=[q_proj, v_proj]
- 评测集：100 条任务（13 条带自动测试用例 + 87 条代码任务）
- 生成方式：chat template + greedy decoding
- 指标：语法通过率（ast.parse）、Pass@1（13 条自动验证）

## 实验结果

| 模型 | 语法通过率 | Pass@1 (13条) | 平均耗时 | 推测训练规模 |
|------|-----------|--------------|---------|-------------|
| base (无微调) | 12.0% | 0.0% | 904s | 0 |
| lora_root_0729 | 22.0% | 7.7% | 1173s | ~100 |
| lora_adapter | 36.0% | 23.1% | 918s | ~200 |
| lora_adapter_v2 | 58.0% | 7.7% | 1019s | ~300 |
| lora_adapter_474 | 88.0% | 38.5% | 550s | 474 |

## 关键发现

1. **语法通过率随知识库规模单调上升**：12% → 22% → 36% → 58% → 88%
2. **Pass@1 提升 38.5 个百分点**：从 base 的 0% 到 474 版本的 38.5%
3. **生成效率显著提升**：从 904s 降到 550s，说明模型学会了直接输出代码，减少冗余
4. **语法正确 ≠ 逻辑正确**：lora_adapter_v2 语法率 58% 但 Pass@1 仅 7.7%，提示验证器需要更严格

## 结论

**SASES 的自迭代闭环已被初步验证有效。** 知识库规模增长与模型能力提升存在明显正相关。下一步应严格量化"知识库规模 vs Pass@1"的曲线。
