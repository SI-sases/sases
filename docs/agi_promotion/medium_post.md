# Two Regional AGI Nodes Promoting SASES

We ran a small, receipt-based experiment with two independent regional AGI nodes.

## The two regions

- Domestic node: Chinese content for a domestic audience
- International node: English content for an international audience

Each node generates its own copy. They do not share a single campaign text.

## What we measure

Not mass posting, not automated friend requests. We measure:

- whether localization is correct
- whether publishing returns a receipt
- whether one region fails independently
- whether results can be reviewed later

## Current status

Both servers run SASES with schema v18.
The next step is one human-approved post per region and a 7-day observation window.

## Principles

Review first, publish second.
No mass automation.
No platform rule evasion.
