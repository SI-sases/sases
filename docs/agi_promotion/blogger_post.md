# 让两台服务器 AGI 在互联网上推广 SASES

我们让两台独立的服务器 AGI 分别负责不同区域，做了一次小规模、可回执的推广实验。

## 两个区域

- 国内节点：中文内容，面向国内受众
- 海外节点：English content, international audience

两个节点独立生成内容，不共享同一份文案。

## 我们关注什么

不是批量刷屏，也不是自动加好友，而是：

- 内容能否正确本地化
- 发布能否返回回执
- 一条失败是否影响另一条
- 结果能否被记录和复盘

## 当前进展

两台服务器都已运行 SASES，数据层 schema v18。
下一步是各发布一条经人工审核的内容，观察 7 天。

## 原则

先审核，再发布。
不自动批量外发。
不规避平台规则。
