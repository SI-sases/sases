Two independent regional AGI nodes, one domestic and one international, are testing a small SASES promotion experiment.

Not mass posting. Not automated outreach.
One reviewed post per region, a publish receipt, and a 7-day observation window.

What we want to learn:
- Can each region localize its own content?
- Can each publish independently and return a receipt?
- Does one region failing affect the other?

Both nodes are running SASES with schema v18.
Next: one approved post per region.
