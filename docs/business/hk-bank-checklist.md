# 香港个人银行卡准备清单

## 用途

- 个人储蓄、出行、投资
- 不作为公司经营收款账户
- 2027 年再评估香港公司账户

## 常见材料

- 内地身份证
- 护照
- 港澳通行证
- 住址证明（近 3 个月水电/银行账单）
- 收入证明 / 工作证明
- 资金来源说明
- 业务计划/用途说明（如有）
- 入境记录/预约确认

## 流程

```text
1. 提前预约银行
2. 准备材料原件
3. 现场面签
4. 说明用途：个人储蓄/投资/出行
5. 了解最低余额、管理费、转账限额
```

## 注意

- 个人卡长期收经营款可能违反银行条款。
- 不隐瞒资金来源。
- 不在账户中处理未申报的业务收入。
- 2027 年根据实际业务决定香港公司。
