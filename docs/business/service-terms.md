# SASES 服务条款（草案）

## 1. 服务内容

- CDK：自托管授权、部署文档、1 年更新、社区支持。
- 托管：云服务器、域名与 HTTPS、备份、版本更新、5×8 支持。
- 部署服务：远程部署、迁移、基础培训。

## 2. 不包含

- 不提供 Claude 账号共享、代登或绕过封禁。
- 不提供未授权平台的批量私信、刷量或规避风控。
- 不承诺第三方平台账号不被限制。
- 不包含服务器、域名、模型 API 费用（托管套餐另有约定除外）。

## 3. 付款与交付

- 订单以人工确认为准。
- CDK 付款后交付授权与文档。
- 托管按月/年预付。
- 部署服务在确认服务器可用后安排。

## 4. 退款

- 未交付：可退。
- 已交付 CDK：原则上不退，质量问题按个案处理。
- 托管：按未使用整月退还，已使用部分不退。
- 部署服务：已开始实施后不退，未开始可退。

## 5. 支持边界

- 支持：安装、配置、升级、常见故障。
- 不支持：客户自定义代码、第三方平台封号申诉、模型供应商故障。
- 支持时间：5×8，紧急问题单独约定。

## 6. 数据与隐私

- 客户数据归客户所有。
- 服务方不主动读取客户数据库内容。
- 备份由客户或托管服务按约定执行。
- 不把客户数据用于训练或案例，除非客户书面同意。

## 7. 合规

客户不得使用 SASES 从事违法、侵权、欺诈、未授权访问或规避平台规则的行为。

## 8. 变更

价格、服务范围和支持方式以订单确认时为准。
