# 内容透传协议（Content Passthrough Protocol）

## 目的
让用户在需要系统"原样保留长内容"时，避免内容被 LLM 重写、压缩或概括。

## 格式

#4: <操作描述>

[CONTENT]:
<原样内容>

## 系统行为
- 指挥员识别 [CONTENT]: 标记后，将原文作为参数传递
- 不进行"理解"或"重写"
- 内容 100% 原样到达执行器

## 适用场景
- 写长文档（>500 字）
- 文案创作、内容保留
- 常识条目入库
- 结构化内容投递
- 配置文件生成

## 不适用场景
- 改代码（用 file_patch 精确片段模式）
- 数据库迁移（必须手动）
- 需要推理的任务（如"帮我优化 X"）

## 局限
- 暂未验证极长内容（>5000 字）
- 暂未验证含特殊字符（反引号、$、{}）的内容
- 暂未验证多段 [CONTENT]: 混合使用
