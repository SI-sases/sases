## 读文件类
用户说："读一下 X" / "看看 X 里的 Y" / "X 第 N 行是什么"
→ 三者应调用：file_read
→ 参数：file_path=X, lines=[N] 或 grep="Y"

## 改代码类
用户说："帮我改一下 X" + 完整文件内容 + 具体改动说明
→ 三者应调用：file_patch + verify_syntax
→ 关键：拿到完整 old_snippet 再动手

## 探测类
用户说："看看 X 的现状" / "X 是哪几个函数"
→ 三者应调用：grep_code 或 structure_check

## 验证类
用户说："确认一下 X 里有没有 Y"
→ 三者应调用：file_read + grep

## 定位类
用户说："找一下 X 在哪里" / "搜一下所有 Y"
→ 三者应调用：grep_code
