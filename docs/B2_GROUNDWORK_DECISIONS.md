# B2 地基决策文档

## 1. 背景

本文档记录 B2 阶段地基相关的关键决策，用于指导后续开发与验收。

## 2. 决策清单

### 决策一：目录结构

- 文档统一存放于 docs/ 目录。
- 命名规范采用大写字母加下划线，例如 B2_GROUNDWORK_DECISIONS.md。

### 决策二：文档格式

- 使用 Markdown 格式。
- 标题层级从一级标题开始，逐级递进。

### 决策三：内容维护

- 每次地基相关变更必须同步更新本文档。
- 变更需记录日期与责任人。

## 3. 验收标准

- 文件存在于 docs/B2_GROUNDWORK_DECISIONS.md。
- 内容包含背景、决策清单、验收标准三部分。
